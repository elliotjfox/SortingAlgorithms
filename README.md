# Sorting Algorithm Visualizer

## About

This is a simple sorting algorithm visualizer written in Java, using JavaFX. You are able to generate random arrays of numbers and watch how different algorithms sort them. 
You can view the algorithm from an overview, watch a slower detailed visualization, or run the algorithm at full speed without a display. 

See below for a list of the algorithms and how they work. 

## Implemented Algorithms

- Bubble
